# 网站里的物理

首页的胶片、作品页和系列页里晾着的照片、首屏落下的字母、光标，都是实时计算出来的，不是预先画好的动画曲线。其余的过渡动画也都由阻尼弹簧的解析解推出。验算脚本：

```bash
node scripts/physics-check.mjs
```

## 1. 阻尼弹簧：所有过渡动画的来源

代码：`site/src/physics/spring.js`

$$\ddot x = -\omega^2 (x - x^\ast) - 2\zeta\omega\dot x,\qquad \omega = 2\pi f$$

- ζ 是阻尼比。ζ < 1 欠阻尼，会先冲过目标一点再回来；ζ = 1 临界阻尼，最快到位且不过冲。
- 过渡动画用的是它的阶跃响应（解析解），把时长归一化成“在动画结束时到达 99.9%”：

$$x(t) = 1 - e^{-\zeta\omega t}\left[\cos\omega_d t + \frac{\zeta}{\sqrt{1-\zeta^2}}\sin\omega_d t\right],\quad \omega_d = \omega\sqrt{1-\zeta^2}$$

- 网站里注册了三种：`spring`（ζ = 0.62，过冲约 8%）、`springFirm`（ζ = 0.85，过冲约 1.5%）、`springCrit`（ζ = 1，不过冲）。离场动画用 `power2.in`，也就是恒力作用下的 x = ½at²。
- 首页和暗房里，镜头跟随滚动也是这样一个弹簧（临界阻尼，0.8 到 0.9 Hz），所以快速滚动时镜头会稍稍落后，停下时平稳到位。

验算：过冲量的理论值是 $e^{-\zeta\pi/\sqrt{1-\zeta^2}}$。

| ζ | 理论 | 数值积分 | 动画曲线 |
|---|---|---|---|
| 0.30 | 37.23% | 36.93% | 37.23% |
| 0.62 | 8.35% | 7.80% | 8.35% |
| 0.80 | 1.52% | 1.16% | 1.52% |

数值积分略低，是半隐式欧拉法自带的一点数值阻尼，以及按帧采样漏掉了峰值。能量 $E = \tfrac12\dot x^2 + \tfrac12\omega^2(x-x^\ast)^2$ 在 300 帧里从未增加。

## 2. 首页：一条胶片做脊柱

代码：`site/src/scene/spine.js`

- 尺寸按 35mm 胶片（ISO KS）：宽 35mm，片孔孔距 4.75mm，片孔 1.98 × 2.79mm，离边 2.01mm，片孔在着色器里按真实间距连续生成，边缘做覆盖率抗锯齿。
- 每一格高 24mm，宽度跟着照片比例走（3:2 横幅宽 36mm，2:3 竖幅宽 16mm），格与格之间留 2mm 片基。竖幅照片是站着的，不裁切。
- 每个系列是一段铺平、正对着你的胶片，格数等于这个系列的照片数，两头各留一格没曝光的空白引片。所以后台多传一张，这一段就长一格。
- 两段之间，胶片在右端向后弯过去，在后面从右往左走回来，途中整整扭转一圈（这时看到的是背面：画面左右相反，隔着片基偏琥珀色），再在左端弯回到前面，落到下一个系列。
- 胶片不可伸长：中心线先密集采样，再按弧长等距放置顶点，所以每一格都保持真实长度，弯折和扭转只改变形状不改变长度。宽度方向尽量保持竖直，再叠加扭转角。
- 镜头：停在一个系列时沿这一段平移，一格一格看过去；照片越多，这一段停留的滚动距离越长。两站之间镜头拉远、侧转，看清弯折和背面，然后落到下一站。

## 3. 作品页和系列页：暗房里晾着的照片

代码：`site/src/scene/darkroom.js`

镜头在视线高度沿正中间往前走。每一排照片正对着你迎面而来，到眼前时化成颗粒消散（每 2 × 2 像素按固定的随机顺序消失），镜头从它原来的位置穿过去。

每张照片是一个刚体摆。支点到重心的距离为 L，绕重心的回转半径为 k 时：

$$\omega^2 = \frac{gL}{k^2 + L^2}$$

挂法不同，支点和能动的方向就不同：

| 挂法 | 能怎么动 | L | k² |
|---|---|---|---|
| 两个木夹、纸胶带 | 只能绕绳子前后摆 | H/2 | H²/12 |
| 一个木夹在正中 | 前后摆，也能在自己平面内左右晃 | H/2 | H²/12（左右晃时为 (W²+H²)/12） |
| 只夹一个角 | 自然斜挂，对角线竖直，重心正好在夹子下方 | D/2 | (W²+H²)/12 |
| 长尾夹加一段细线 | 摆长更长，摆得更慢 | ℓ + H/2 | H²/12 |

（W、H 为照片含白边的宽和高，D 为对角线，ℓ 为线长。）

从镜头看，是整排晾片架朝你移过来。在架子的参考系里，照片受到重力和与加速度相反的惯性力，并在静止的空气里受到二次阻力：

$$\ddot\theta = \frac{L}{k^2+L^2}\left(S\,a\cos\theta - g\sin\theta\right) - 2\zeta\omega\dot\theta + \frac{\kappa}{L}(V-v)\,|V-v|$$

- V 是架子的速度（即镜头速度的相反数），a 是它的加速度，v 是照片中心的速度。
- 滚动能让场景移动得比真实的晾片架快得多，所以加速度按 S = 0.03 缩小，空气阻力 κ = 0.008，阻尼比 ζ = 0.12，让摆幅保持在几度。
- 所以：滚动时照片微微后仰；滚动突然停下，夹子跟着架子停住，照片还带着往前的速度，于是往前荡，再来回摆几次停下。
- 能在平面内晃动的照片（一个木夹、只夹一个角、细线），还会被绕过照片的气流涡旋轻轻推向两侧。
- 绳子是麻绳，在自重下下垂成悬链线（这个跨度下近似抛物线）；每根绳子的粗细、下垂、颜色、毛刺数量都不同，纤维有短有长。
- 地面是湿的，每张照片在地上有一个变暗、越往下越淡的倒影，倒影里的转角与照片相反。

抗锯齿：照片外边缘和白边与照片的交界，都按屏幕上的一个像素宽度（`fwidth`）做平滑过渡；外边缘把覆盖率写进透明度，再由多重采样的 alpha to coverage 变成平滑的边，不需要给透明物体排序。照片纹理开启 mipmap 和各向异性过滤。

验算：

| 挂法 | 理论频率 | 模拟频率 |
|---|---|---|
| 两个木夹，1.37 × 0.95 | 0.626 Hz | 0.626 Hz |
| 长尾夹加 0.25 的细线 | 0.547 Hz | 0.547 Hz |
| 只夹一个角 | 0.473 Hz | 0.473 Hz |

以每秒 4 个单位匀速滚动后突然停下：滚动时后仰 0.7°，停下后最大摆 1.7°，2.6 秒后小于 0.5°。在浏览器里用滚轮快速滚动再停下时，实测后仰约 6°，往前荡约 6°，4 秒后只剩 1° 到 2°。

## 4. 首屏：落下的字母

代码：`site/src/hero.js`

- 字母在重力下落下（1 米画成 400 像素，所以 g = 3920 px/s²），落到基线上反弹，恢复系数 e = 0.32，直到停稳。每次弹起的高度是上一次的 e² ≈ 0.10 倍。
- 落定之后，每个字母挂在一个弹簧上（f = 2.2 Hz，ζ = 0.45）。鼠标扫过时把自己速度的四分之一按高斯衰减传给字母（最多 900 px/s），字母被推开再弹回来。
- “QUIETIME”的字母像一张镂空的模板压在照片上，照片跟着鼠标在一个软弹簧上缓缓滑动。

验算：从 600 像素高处落下，弹起高度 60.2、5.8、0.5 像素；理论值 600·e² = 61.4，之后每次乘 0.102。

## 5. 光标

代码：`site/src/cursor.js`

- 中间的点：f = 16 Hz、ζ = 1，紧紧跟着鼠标。
- 外圈：f = 3.4 Hz、ζ = 0.6，有质量、慢半拍。移动时沿速度方向拉长 1 + s、垂直方向收窄 1/(1 + s)，面积不变，像一滴有惯性的软体。
- 指到链接或按钮时，四个对焦角标用弹簧（f = 5 Hz、ζ = 0.75）吸附到它的四周，停稳后变成琥珀色，像相机合焦确认。点击时外圈像按快门一样被踢一下再弹回。

## 6. 减少动态

系统开启“减少动态效果”时，不加载三维场景，首页显示一条静止的胶片，作品页和系列页显示原来的版式；字母直接就位，过渡只保留淡入淡出。

## 7. 时间步：帧率低也不会变慢

代码：`site/src/physics/spring.js` 里的 `frameTime`、`substeps`

所有模拟（弹簧、暗房里的摆、首屏落字、光标）都按真实经过的时间积分，每一小步不超过 1/240 秒。以前每帧最多只算 0.05 秒，设备卡到 20 帧以下时，模拟出来的时间就比真实时间慢，摆动和镜头像慢放。现在一帧最多补算 0.25 秒（60 小步），只有切到后台这类真正的停顿才会被跳过，不会醒来时一下子补算很久。

验算（`physics-check.mjs` 第 4 项）：同样 2 秒的运动，在 120、60、20、7 帧下的终点和 240 帧时相差不到 3×10⁻⁴。

## 8. 暗房：软的限位

照片摆过 ±0.35 rad（约 20°）以后，绳子和旁边的照片会挡住它。以前在 ±0.5 rad 处直接截断，照片会突然停住；现在超出的部分加一个随超出量平方增长、并带阻尼的回复：

$$\ddot\theta_{\text{stop}} = -\operatorname{sign}(\theta)\,k\,o^2 - c\,o\,\dot\theta,\qquad o = |\theta| - 0.35,\quad k = 900,\ c = 40$$

侧向摆动（φ）同样处理，起点 0.28 rad。

验算（第 5 项）：给一张已经以 5 rad/s 摆动（约为滚动能造成的五倍）的照片再加上滚动能给的最大推力，最大角度约 35°；肉眼看到的角速度每一小步最多变化 0.31 rad/s，原来的硬截断是 3.67 rad/s。

照片静止且没有滚动时停止积分，有滚动就醒来。
