# 网站里的物理

首页的胶片和背景里的显影液都是实时仿真，不是预先设计好的动画曲线。其余的过渡动画也都由阻尼谐振子的解析解推出。验算脚本：

```bash
node scripts/physics-check.mjs
```

## 1. 阻尼弹簧：所有过渡动画的来源

代码：`site/src/physics/spring.js`

$$\ddot x = -\omega^2 (x - x^\ast) - 2\zeta\omega\dot x,\qquad \omega = 2\pi f$$

- ζ 是阻尼比。ζ < 1 欠阻尼，会先冲过目标一点再回来；ζ = 1 临界阻尼，最快到位且不过冲。
- 过渡动画用的是它的阶跃响应（解析解），把时长归一化成“在动画结束时到达 99.9%”：

$$x(t) = 1 - e^{-\zeta\omega t}\left[\cos\omega_d t + \frac{\zeta}{\sqrt{1-\zeta^2}}\sin\omega_d t\right],\quad \omega_d = \omega\sqrt{1-\zeta^2}$$

- 网站里注册了三种：`spring`（ζ = 0.62，过冲约 8%）、`springFirm`（ζ = 0.85，过冲约 1.5%）、`springCrit`（ζ = 1，不过冲）。离场动画用 `power2.in`，也就是恒力作用下的 x = ½at²。
- 光标：圆点 f = 14 Hz、ζ = 1；光圈 f = 3.2 Hz、ζ = 0.62，所以光圈会慢半拍并轻微回弹。

验算：过冲量的理论值是 $e^{-\zeta\pi/\sqrt{1-\zeta^2}}$。

| ζ | 理论 | 数值积分 | 动画曲线 |
|---|---|---|---|
| 0.30 | 37.23% | 36.93% | 37.23% |
| 0.62 | 8.35% | 7.80% | 8.35% |
| 0.80 | 1.52% | 1.16% | 1.52% |

数值积分略低，是半隐式欧拉法自带的一点数值阻尼，以及按帧采样漏掉了峰值。能量 $E = \tfrac12\dot x^2 + \tfrac12\omega^2(x-x^\ast)^2$ 在 300 帧里从未增加。

## 2. 显影液：不可压缩流体

代码：`site/src/physics/fluid.js`，方法是 Jos Stam 的 *Stable Fluids*（SIGGRAPH 1999）。

$$\frac{\partial \mathbf u}{\partial t} = -(\mathbf u\cdot\nabla)\mathbf u - \frac{\nabla p}{\rho} + \mathbf f,\qquad \nabla\cdot\mathbf u = 0$$

每一步：
1. **涡量约束**：$\mathbf f = \varepsilon\,\min(1, |\omega|/\omega_0)\,(\mathbf N \times \omega)$，$\mathbf N = \nabla|\omega|/|\nabla|\omega||$，把数值扩散抹掉的小漩涡补回来。数值扩散来自沿流线插值，流得越快扩散越多，所以补偿也按 $\min(1, |\omega|/\omega_0)$（$\omega_0 = 1$/s）缩放：液体快静止时补偿随之消失，不会无休止地喂养微弱的涡。
2. **半拉格朗日平流**：沿流线往回追溯取值，任意时间步都稳定。
3. **压力投影**：用超松弛迭代（SOR，ω = 1.75，30 次，用上一帧的压力作初值）解 $\nabla^2 p = \nabla\cdot\mathbf u$，再减去 $\nabla p$，使流场无散度。
4. **染料平流与衰减**：衰减按 $e^{-kt}$ 计算，与帧率无关。

网格：电脑 96×54，手机 42×76。墨迹的深浅来自染料浓度，再加上一点涡量大小 |ω| 的阴影，所以没有墨的地方也能隐约看到旋涡。墨色有一个软上限：$\alpha = \alpha_{max}(1 - e^{-a/\alpha_{max}})$，$\alpha_{max} = 96/255$，浓处只会渐渐逼近这个深度，不会堆成一块死黑。染料按 $e^{-0.7t}$ 消退。

休眠：最快的格子低于 0.15 格/秒（宽屏上约 2 px/s，推不动胶片），且染料浓度低于 0.002（画出来不到一级透明度）时，液体停止计算。

验算：搅动后的流场经过一次投影，散度均方根剩下约 10% 到 14%；不再施力时，2 秒后动能衰减到原来的约 7%，不会发散；涡变弱以后衰减率约 0.54/s，接近设定的阻尼 0.6/s，说明涡量约束确实退场了；剧烈搅动后约 10 秒可以休眠。

## 3. 胶片：有长度、有惯性、受阻力的长条

代码：`site/src/physics/ribbon.js`

胶片被看作一串质点，每格是两点之间不可伸长的一段。每个质点：

$$\mathbf a = -\omega(u)^2(\mathbf x - \mathbf x^\ast) - 2\zeta(u)\omega(u)(\mathbf v - \mathbf v^\ast) - \beta|\mathbf v - \mathbf w|(\mathbf v - \mathbf w) + g(u)\,\hat{\mathbf y}$$

- $\mathbf x^\ast$：它在空间曲线上应在的位置。曲线是一条向两侧退向远处的大圆弧（半径 2.4 倍屏宽），超过角度 a 之后沿切线笔直延伸，再叠加缓慢的上下和前后起伏。透视距离为 p 时，沿角度 a 离开的直线会消失在离画面中心 $p\cot a$ 的地方，所以取 $a = \min(1, \arctan\frac{p}{W/2 + 240})$，让这个消失点落在屏幕之外：远处的胶片只会跑出画面，不会绕回来。
- u：这个点离“片门”（画面中央正在看的位置）的距离。片门半宽 0.28 倍屏宽，比一格照片的一半还宽，所以停在中央的那一格是平的；片门附近 f = 1.7 Hz、ζ = 0.95，越往外越松，远端 f = 0.5 Hz、ζ = 0.3。
- 阻力：二次阻力 $\tfrac12\rho C_d A |v|v$，β = 0.0007 /px。$\mathbf w$ 是该处流体的速度，所以水流会推动胶片。
- 重力：远离片门处 240 px/s²，让两端微微下垂。
- 扭转：$\ddot\theta = -\omega_t^2\theta - 2\zeta_t\omega_t\dot\theta + \kappa\,\partial(v_y - w_y)/\partial s$，由横向水流的剪切驱动，最多 ±24°。
- 不可伸长：每个子步做 12 轮位置约束投影（Position Based Dynamics，Müller 等 2007）。
- 片基有刚度：相邻两格最多折 24°。用三角形弯曲约束（Kelager、Niebe、Erleben 2010）：中间节点离三点重心的距离不得超过 $h_0 = \sqrt{a^2 + b^2 - 2ab\cos 24^\circ}\,/\,3$（a、b 为两格长度），超过时把中间点拉回、两端反向移动，重心不变。每一轮先做弯曲、后做长度，所以每一步结束时胶片都不会被拉长。
- 缓流：让两端摆动的那股缓慢水流由滚动搅起，强度 c 按 $e^{-t/4}$ 自行衰减；c 低于 5% 且所有节点慢于 0.5 px/s 时，胶片停止计算。
- 积分：半隐式欧拉，固定子步 1/240 秒。

双向耦合：胶片相对液体运动时，把 $0.35\times$ 相对速度的动量和少量染料注入流体（阻力的反作用）；流体速度又进入上式的 $\mathbf w$。

验算（以 1400 px/s 拉动 3 秒后突然停止）：
- 任意一格的最大拉伸：0.03%，相当于胶片不会被拉长。
- 相邻两格的最大折角：24.0°，正好在上限上。
- 自由端因惯性与阻力落后：约 157 px。
- 停止后速度降到 2 px/s 以下用时 9.9 秒，12.2 秒后休眠。理论上缓流降到 5% 需要 $4\ln 20 \approx 12.0$ 秒，之后最松的一端按 $e^{-\zeta\omega t}$ 停下。
- 在 900、1440、2560 px 宽的屏幕上，离片门超过 2.6 倍屏宽的格子没有一格出现在画面里。

### 过片定位

滚动停下 0.14 秒后，离片门最近的那一格由一个临界阻尼弹簧拉到正中（f = 1.1 Hz，ζ = 1）。临界阻尼的阶跃响应 $x(t) = 1 - e^{-\omega t}(1 + \omega t)$ 在 $9.23/\omega \approx 1.34$ 秒时到达 99.9%，所以这段滚动用时 1.34 秒、不过冲，就像相机过片机构的卡位。

### 相机在每一格里

每一格自带完整的相机：先绕画面中心偏上的点做透视（距离 1500 px，原点在舞台 50% 42%），再加整体倾斜 rotateX(9°) rotateZ(−2.2°)，最后是这一格自己的位置和姿态。页面里没有共享的 preserve-3d 场景，浏览器不需要为它排序或裁切，远近遮挡由我们按每格中心的深度排序（画家算法，z-index）。舞台用 position: sticky 停留胶片那么长的距离，结束后随页面自然滚走。

## 4. 手机上的胶片

手机上胶片竖放、自然滚动。每一格是一个耦合的阻尼振子：

$$\ddot\theta_i = -\omega^2\theta_i - 2\zeta\omega\dot\theta_i + k(\theta_{i-1} + \theta_{i+1} - 2\theta_i) - \alpha\,a_{\text{scroll}}$$

滚动加速或减速时，惯性让胶片前后倾斜，扰动沿着胶片传下去；水平方向则随流体摆动。页面静止、每一格都停稳、墨也散尽后，仿真停止。

## 5. 减少动态

系统开启“减少动态效果”时，所有仿真都不运行，胶片静止竖放，过渡只保留淡入淡出。
