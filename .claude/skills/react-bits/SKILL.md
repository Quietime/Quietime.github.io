# React Bits

React Bits is David Haz's open collection of animated UI pieces. Every component exists as JavaScript + CSS,
JavaScript + Tailwind, TypeScript + CSS and TypeScript + Tailwind, and is installable with the shadcn or jsrepo
CLI. Many are built on GSAP, three.js or OGL, which this project already uses.

- Index for agents (always current): https://www.reactbits.dev/llms.txt
- Registry: `https://reactbits.dev/r/<Name>-<JS|TS>-<CSS|TW>.json` (shadcn registry items; the source is in `files[].content`)
- Component pages: `https://www.reactbits.dev/<category>/<kebab-name>`, e.g. `/text-animations/split-text`

## Find and read a component

```bash
node .claude/skills/react-bits/scripts/rb.mjs list scroll text      # search names and descriptions
node .claude/skills/react-bits/scripts/rb.mjs get ScrollFloat       # print JS + CSS source and its npm deps
node .claude/skills/react-bits/scripts/rb.mjs get Noise TS-CSS      # another variant
```

The script only prints; it never writes into the repository.

## Using it on this site (vanilla JS, no React)

This site is static HTML generated by `scripts/generate.mjs` with one module, `site/src/main.js`, plus GSAP,
Lenis and three.js. Do **not** add React, ReactDOM or Tailwind to use a single effect. Instead:

1. Read the JS-CSS variant with `rb.mjs get <Name>`.
2. Port the effect: JSX markup becomes markup in `generate.mjs` (or nodes created in JS); `useRef` becomes a
   query; `useEffect` setup becomes a function called from the page's init in `main.js`, and its cleanup
   becomes a returned dispose function; `motion`/`framer-motion` tweens become GSAP tweens with the project's
   spring eases (`spring`, `springFirm`, `springCrit`, see `site/src/physics/spring.js`).
3. Keep the project's rules: respect `prefers-reduced-motion` (the `reduce` flag), touch devices (`fine`),
   the three languages (no hard-coded copy, put words in `scripts/i18n.mjs`), and the film / darkroom look.
   CSS goes into `site/src/styles.css` using the existing tokens (`--bg`, `--fg`, `--accent` ...).
4. Mention in a code comment which React Bits component it was ported from.

In a React project the official route is the CLI or the shadcn MCP server:

```bash
npx shadcn@latest add https://reactbits.dev/r/SplitText-JS-CSS
npx jsrepo@latest add https://reactbits.dev/r/SplitText-JS-CSS
# MCP: add "registries": { "@react-bits": "https://reactbits.dev/r/{name}.json" } to components.json,
# then: npx shadcn@latest mcp init --client claude
```
